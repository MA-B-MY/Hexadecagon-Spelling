# 🏃‍♂️ Hexadecagon Spelling

My first solo (not web based) project and first repository! **Hexadecagon Spelling** is a fast-paced browser game and Chrome Extension that combines endless running physics with word-building mechanics.

---

## 🎮 How to Play

1. **Controls:**
   * **[W] / [↑]** — Jump (Press twice for Double Jump!)
   * **[A] / [D]** — Move Left / Right
   * **[SPACE]** — Submit your word
   * **[P]** — Pause Game

2. **Rules:**
   * Collect floating letter clouds as your character rolls forward.
   * Words must be at least 2 letters long and match real English dictionary entries.
   * Press **Spacebar** to cash in valid words for bonus points.
   * **⚠️ DANGER:** Submitting an invalid word causes your character to explode!
   * **⚠️ DANGER:** Don't let moving stone obstacles squeeze you off the left edge of the screen!

---

## ✨ Features

* **Customizable Character:** Native color picker lets you select any color for your rolling hexadecagon player.
* **Dynamic Speed Intervals:** Game speed increases every 30 seconds to test your reaction time.
* **Chrome Extension Ready:** Built to run smoothly inside a fixed 800x500 popup.
* **Interactive Word Library:** Built-in dictionary viewer to search and explore valid game words.
